# test-chat

# Lista mea

Aplicație de sarcini în română, fără dependențe externe. Permite adăugarea, bifarea, filtrarea și ștergerea sarcinilor. Datele sunt salvate în localStorage, separat pentru fiecare browser. Nu există conturi sau sincronizare între dispozitive.

## Pornire

Ai nevoie de Node.js 18 sau mai nou.

```sh
cd /workspace/test-chat
npm start
```

Serverul ascultă pe portul 3000. Poți schimba portul folosind variabila `PORT`.
